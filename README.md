# ElectroMart

ElectroMart is an e-commerce web and mobile application developed as a CSE445L course project. The system will allow users to browse products, search and filter items, manage cart and wishlist, place orders, track order status, and review purchased products. Administrators will be able to manage products, users, orders, invoices, and sales reports.

## Project Type

Web and mobile based e-commerce system.

## Tech Stack

- Backend: Django, Django REST Framework
- Frontend: Flutter Web and Flutter Mobile
- Database: PostgreSQL
- Testing: Selenium, Postman
- CI/CD: GitHub Actions
- Version Control: Git and GitHub

## Target Users

| User / Stakeholder | Description |
|---|---|
| Guest Visitor | Can browse, search, and view product details without creating an account |
| Registered Customer | Can register, login, manage profile, use cart/wishlist, place orders, track orders, and write reviews |
| Administrator | Can manage products, orders, users, invoices, and sales reports |
| Course Instructor | Evaluates the project progress and final implementation |

## Main Features

- User registration, login, logout, and profile management
- Role-based access control
- Product catalog with categories such as Phones, Laptops, Accessories, and TVs
- Product search and filtering by price, brand, category, and rating
- Shopping cart and wishlist
- Checkout and Cash on Delivery order placement
- Order history and status tracking
- Product reviews and star ratings by verified buyers
- Invoice generation
- Admin dashboard for product, order, user, and sales management
- Automated UI and API testing
- CI/CD pipeline using GitHub Actions
